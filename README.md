#Автотест API получения заказа по треку

Проект содержит автотест для проверки сценария:

1. Создание нового заказа.
2. Получение номера трека из ответа.
3. Получение данных заказа по треку.
4. Проверка кода ответа `200`.

#Файлы проекта

- `configuration.py` — URL сервиса и пути API.
- `data.py` — заголовки и тестовые данные заказа.
- `sender_stand_request.py` — функции для отправки HTTP-запросов.
- `get_order_by_track_test.py` — автоматизированный тест.
- `.gitignore` — файлы и папки, которые не нужно добавлять в проект.
- `README.md` — описание проекта и инструкция по запуску.

#Используемые технологии

- Python
- pytest
- requests

#Запуск теста

Откройте терминал в корневой папке проекта и выполните:

```bash
python -m pytest -s get_order_by_track_test.py
```
